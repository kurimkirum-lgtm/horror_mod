# DON'T MAKE A SOUND — Horror Mod

Minecraft horror mod focused on sound-driven AI, sanity, an analog radio, and adaptive entities.

## Development baseline

- Minecraft: 1.21.1
- Java: 21
- Loader: NeoForge
- Mod ID: `horror_mod`

This repository is being initialized with a minimal, offline-first foundation. AI-provider integrations are optional and will not be required for core gameplay.
